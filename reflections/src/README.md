# Export chat transcript as md

Ref: https://dev.to/rashidazarang/export-your-chatgpt-conversations-to-markdown-pdf-cfj

## Steps for Markdown Export

1. Open the ChatGPT conversation you wish to export.
1. Right-click anywhere on the page and select ‘Inspect’ from the context menu.
1. In the panel that opens, navigate to the ‘Console’ tab.
1. Copy and paste the JavaScript snippet into the console input field, then press Enter.
